# Syraxen

Syraxen, Ordu/Altınordu merkezli bağımsız bir dijital stüdyo tanıtım sitesidir. Web tasarımı ve geliştirme, özel yazılım çözümleri, dijital ürün deneyimi ve bakım hizmetlerini tanıtır.

## Geliştirme

pnpm install
pnpm --filter @workspace/syraxen run dev

## Üretim derlemesi

pnpm --filter @workspace/syraxen run build

## Site içeriği

Site; hizmetler, çalışma süreci, kurucu tanıtımı, sık sorulan sorular ve iletişim bölümlerini içerir. Portföy kartları gerçek müşteri çalışmaları değil, açıkça etiketlenmiş konsept örnekleridir. İletişim formu bilgileri doldurulmuş bir e-posta taslağı açar.
